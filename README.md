## 🚀 Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Copy .env.example and paste into .env

# 3. Start Mockoon server
# - Open Mockoon app
# - Click "Open local environment"
# - Select mockoon-config.json
# - Click Start (red play button)

# 4. Start dev server
npm run dev
```
